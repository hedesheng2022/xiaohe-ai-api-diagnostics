# Xiaohe AI API Diagnostics

This GitBook entry point documents a small credential-free HTTP reachability
checker for the public Xiaohe endpoints.

- [Xiaohe AI](https://www.xiao-he-ai.com/)
- [Xiaohe API](https://api.xiao-he.top/)
- [Codex API configuration guide](https://ai.xiao-he.top/codex-api.html)
- [Claude Code API configuration guide](https://ai.xiao-he.top/claude-code-api-config.html)

The checker does not send credentials and cannot prove that a provider accepts a
particular model or protocol.
