Xiaohe AI API Diagnostics
=========================

This small project checks whether a public Xiaohe endpoint is reachable over
HTTP without sending credentials. It is intentionally narrower than an API
client: a successful status response cannot prove that a route, model, or
authentication scheme is supported.
